# 検証結果

## ソースとZIP展開後の実動作

実行環境：Python 3.12、Chromium、Playwright。ソースと、配布ZIPを別フォルダへ展開したコピーをそれぞれHTTPサーバーで配信して検証しました。

- 幅320・390・768・1366・1920pxで全12ページを検査。ソース60画面＋ZIP展開後60画面、計120画面を通過。
- 横方向のはみ出し、HTTPリソースエラー、JavaScript実行エラー、CSP／SRIエラーなし。
- CSS2ファイルと同梱フォントが読み込まれ、実際のフォントで表示されることを確認。
- 各ページのh1とmainがそれぞれ1つ。内部ページ・アンカーの参照切れなし。
- Windows/Mac用の起動ファイルと共通Pythonサーバーを同梱。ZIP展開後の共通起動スクリプトで配信を確認。

## データが登録された状態の機能検証

ブラウザ内の通信差し替えでテストデータを使用し、公開用JSONには書き込んでいません。

- ソースは320・390・768・1366px、ZIP展開後は390pxで機能検証。
- 2枚のヒーロースライド、動きを減らす設定による初期停止、プロフィール写真、Journal。
- モバイルメニューの開閉とEscapeキー。
- 次戦・開催時刻を含むカウントダウン・完了済みの最新結果・レース詳細の開閉。
- ニュースカテゴリーとURLクエリ連携、未来日の非表示、記事遷移・本文・メタ情報・Article構造化データ。
- PersonのsameAs、SportsEvent構造化データ。
- Google Formsはクリック前にiframeがなく、クリック後にembedded=trueで読み込むこと。外部サービスへの実送信は行っていません。
- HTMLに見える文字列を実行せず文字として表示し、javascript: URLや別ドメインを装ったSNSリンクを拒否すること。
- SNS全4件を設定した状態でも320・390・768・1099・1100・1366pxで表示がはみ出さないこと。
- 実在しないプロフィール画像で、画像読込失敗の案内が表示されること。

## 納品ファイルと安全性

- `python3 scripts/verify-site.py`：全12ページ、CSSのフォント参照、JS imports、JSON、sitemap XML、SEO、CSPハッシュ、ローカルCSS・main.jsのSHA-384 SRI、起動ファイルを確認。
- `scripts/update-csp.py`を連続実行しても2回目にファイルが変わらないことを確認。
- `git diff --check`を確認。
- 配布ZIPはGitの追跡済みファイルに限定せず、作業フォルダの実ファイル一式から生成。CSS・JS・JSON・画像・フォント・資料・起動ファイルを含み、`.git`は除外。
- ZIP内部CRCを検査し、最終ZIPを再展開した全ファイルが元のソースとバイト単位で一致することを確認。
- PC／タブレット／携帯／小型携帯の画面画像は`docs/previews/`に同梱。

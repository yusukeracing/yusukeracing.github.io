# YUSUKE IKEDA — Official Support Website

宮城県角田市出身、全日本ロードレース選手権に挑む池田優介の応援サイトです。HTML / CSS / JavaScriptのみで動作し、GitHub Pagesで公開できます。

## ローカルで見る

```sh
cd /workspace/yusukeracing.github.io
python3 -m http.server 8000 --bind 127.0.0.1
```

別のターミナルから `curl http://127.0.0.1:8000/` で配信を確認できます。ビルド・npmインストール・サーバーへの個人情報保存は不要です。JavaScriptのモジュールを使用するため、HTMLを直接ダブルクリックするのではなくHTTPサーバー経由で確認してください。

## ファイル構成

- `index.html`：TOP
- `profile.html`：プロフィール・年表
- `race.html`：次戦・日程・戦績
- `sponsor.html`：法人・企業スポンサー
- `support.html`：個人の応援・支援
- `news.html`：ニュース・詳細記事
- `contact.html`：問い合わせ入力・確認・メール作成
- `css/style.css`：全ページ共通デザイン
- `css/fonts.css`, `assets/fonts/`：ローカルフォント（Barlow Condensed / Noto Sans JP、SIL OFL）
- `js/site-data.js`：更新用の情報
- `js/main.js`：メニュー・写真切替・日程・記事・問い合わせ
- `DESIGN.md`：サイト設計とUI方針

## 情報を更新する

`js/site-data.js`を編集します。設定例はファイル内のコメントを参照してください。文字列にシングルクォートを含める場合はエスケープしてください。変更後は `node --check js/site-data.js` を実行すると構文ミスを確認できます。

| 項目                     | 設定                                         |
| ------------------------ | -------------------------------------------- |
| 所属・参戦クラス         | `team` / `category`                          |
| お問い合わせ先           | `email`：公開可能なメールアドレス            |
| SNS                      | `social`：各プロフィールの完全なHTTPS URL    |
| 本人写真                 | `heroImages`：写真パス、代替テキスト、説明   |
| 経歴年表                 | `career`                                     |
| 年間ランキング・耐久戦績 | `seasonResults`                              |
| 日付があるレース・次戦   | `races`：開催日・終了日・サーキット・結果    |
| 活動報告                 | `news`：日付・カテゴリー・見出し・要約・本文 |
| 個人支援先               | `supportUrl`：正式受付のHTTPS URL            |
| 法人向けPDF資料          | `sponsorPdf`：PDFの相対パス                  |

次戦は日本時間の終了日まで有効な日程から自動選択します。終了日が未指定なら開催日の23:59:59まで有効です。結果のない順位・日程・経歴は生成しません。ニュース記事は配列に追加するとTOPの最新3件とNEWSの一覧・詳細に反映されます。

### 本人写真へ差し替える

初期の `images/hero/racing.webp` と `pit.webp` はAIで作成した架空のイメージ画像で、池田選手本人や実際の車両・競技活動を写したものではありません。画面とOGPにも明示しています。公開用には権利を確認した本人写真への差し替えを推奨します。

1. WebPの写真を `images/hero/` に追加します。推奨は横1600〜2000px程度です。
2. `heroImages` に `{ src: 'images/hero/写真.webp', alt: '写真の具体的な説明', caption: '撮影場所・クレジット', illustrative: false }` を追加します。
3. 2枚以上あると6秒ごとにクロスフェードします。手動切替・一時停止に対応し、動きを減らす設定と非表示タブでは自動切替が止まります。
4. `profile.html` / `index.html`の紹介写真、ラベル・説明文も本人写真に変更します。
5. `images/ogp.jpg` は別画像です。実写真で1200×630pxのOGP画像を用意し、各HTMLの `og:image:alt` も更新してください。

写真の見え方は `css/style.css` の `.hero-slide` の `object-position` で調整できます。画像は権利・掲載許可・撮影者クレジットを確認してください。

### お問い合わせ

メールアドレス未登録時は、入力・確認まで動作し、送信できない旨を明示します。`email` 登録後は確認画面に「メールアプリで下書きを作成」が表示されます。メールアプリから実際に送信する必要があり、このサイト自体が送信完了を確認する機能はありません。自動送信が必要な場合は、別途HTTPSフォームサービスを契約し、送信先だけをCSPに追加する実装が必要です。秘密鍵をフロントエンドに置かないでください。

個人情報取扱いの説明は `contact.html` にあります。公開前に運営者・連絡先・実際の取り扱い方針を確認してください。入力データをサーバーやlocalStorageへ保存しません。

## GitHub Pages公開とセキュリティ

1. GitHubの Settings → Pages で、公開対象を `main` ブランチのルートに設定します（既存の公開設定がある場合は維持）。
2. **Enforce HTTPS** を有効にしてください。独自ドメインを使う場合は証明書が有効なことも確認します。
3. GitHubアカウントで2段階認証またはパスキーを有効にし、リポジトリの編集者を必要最小限にします。
4. `main` のブランチ保護／RulesetでPull Requestとレビュー、`Static site checks` の成功を必須にします。管理者の迂回も制限してください（利用可能な機能は契約プランによります）。
5. 変更履歴・公開結果を確認し、依存するGitHub Actionの固定バージョンを定期的に更新します。CIは検証のみで、デプロイや公開設定の変更は行いません。

全HTMLにCSPとリファラーポリシーを設定しています。外部JavaScript・外部フォント・インラインスクリプト・HTML挿入を避け、画像・フォントは同一サイト内に配置しています。設定データは `textContent` で描画し、リンクはHTTPSまたは同一サイトの相対パスに限定します。CIはローカルリンク・画像の代替テキスト・CSP・外部／インラインスクリプトなどを確認します。

HTTPSは通信の盗聴対策、CSPは一部の不正スクリプト実行対策です。GitHubアカウントが侵害された場合のソース改ざんは、サイトのコードだけで完全には防げません。GitHub Pagesでは独自のHTTPレスポンスヘッダーを任意に設定できないため、`frame-ancestors` などのヘッダーによる対策が必要なら対応ホスティングを検討します。また、メールの機密性は使用するメールサービスにも依存します。

## 検証

```sh
python3 tests/check_site.py
node --check js/main.js
node --check js/site-data.js
```

制作時にはChromiumで以下を確認しました。

- 7ページ × 1920 / 1366 / 768 / 390 / 320px：横スクロールなし
- 写真の自動切替・停止・手動切替・動きを減らす設定
- メニューのEscape・フォーカス循環・ページ移動
- 2021〜2025年の経歴5件、年間・耐久戦績9件、年別フィルター
- ニュースのカテゴリー切替・登録後の詳細表示
- 日程登録後の次戦選択・日本時間のカウントダウン
- 問い合わせ確認、メール未登録時の表示、登録後のメール下書き
- HTMLとして解釈されない入力・設定テキスト
- axe-coreによるWCAG 2.1 A / AAの自動検査：7ページ × PC・スマートフォンで検出違反0（アニメーション停止状態で検査）

実際のGitHub Pages公開、公開ドメインでのHTTPS、問い合わせメールの配達は、公開・連絡先設定後に別途確認が必要です。
